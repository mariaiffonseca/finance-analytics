# Purpose

This document defines the core business concepts of Finance Analytics.

It describes the domain independently from Android, databases or APIs.

If a concept appears in the application, it should exist here first.

---

# Domain Overview

Transactions are the raw input.

Analytics transforms transactions into knowledge.

Insights and recommendations are the product delivered to the user.

```
Transactions
      │
      ▼
Analytics Engine
      │
      ▼
Insights
      │
      ▼
Recommendations
```

---

# Core Entities

## Transaction

Represents a financial operation imported from a data source.

### Required fields

- id
- date
- amount
- currency
- description
- merchant
- category
- account (optional)

Notes:
- Transactions are immutable once imported.
- Manual edits should create metadata, not overwrite the original record.

---

## Merchant

Represents a normalized merchant.

Example:

Amazon EU
Amazon Marketplace
AMZN Digital

↓

Amazon

### Fields

- id
- name

Future:
- logo
- website
- aliases

---

## Category

Represents how a transaction is classified.

### Fields

- id
- name
- icon
- color

Categories should remain stable to preserve historical analytics.

---

## Monthly Summary

Aggregated financial information for a given month.

Contains:

- total income
- total expenses
- savings
- category breakdown
- month-over-month comparison

---

## Insight

The most important entity in the application.

Insights are generated by the Analytics Engine.

Examples:

- Restaurant spending increased by 18%.
- A new recurring subscription was detected.
- Grocery spending is lower than your yearly average.

### Fields

- id
- type
- priority
- title
- description
- confidence
- generatedAt

---

## Recommendation

A suggested action derived from one or more insights.

Examples:

- Review subscriptions.
- Reduce restaurant spending.
- Create a grocery budget.

Fields:

- id
- title
- description
- priority
- relatedInsightId

# Relationships

Transaction
    ├── Merchant
    └── Category

Monthly Summary
    └── Transactions

Insight
    └── Monthly Summary / Transactions

Recommendation
    └── Insight

---

# Domain Rules

- Transactions are the source of truth.
- Insights are derived data.
- Recommendations never exist without supporting insights.
- Categories are stable over time.
- Analytics never modifies imported data.
