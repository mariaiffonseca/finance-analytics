# Finance Analytics

Personal analytics platform focused on understanding financial behaviour through insights instead of transaction management.

> This repository is under active development. See `docs/` for engineering and project documentation.

## Structure

- `android/` — Android application
- `python/` — Backend services
- `analytics/` — Data analysis and notebooks
- `docs/` — Engineering and project documentation
- `assets/` — Branding and screenshots
